end-to-end pipeline · browser → server → back

Sign → word → sentence.

A scripted replay of the real ASL Guide translation flow. MediaPipe tracks landmarks in-browser, a TF.js classifier labels each sign, letters buffer into words, then a LangGraph agent applies 11 ASL grammar rules to produce a natural sentence.
